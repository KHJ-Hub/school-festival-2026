시작하기 (설치 없음, 브라우저만)

  1. Chrome으로 github.com 가입 (멈추면 시크릿 창 → 그래도 안 되면 Edge) → 학교 구글 메일로 가입, 사용자 이름은 별명
  2. Settings → Emails → Keep my email addresses private 켜기
  3. 사용자 이름을 선생님께 알려 주고, 메일의 초대 수락 (메일 제목에 school-festival-2026이 있는지 확인)
  4. 저장소 페이지에서 내 브랜치 선택 → Code → Codespaces → Create codespace (처음엔 몇 분 걸림, 기다리기)
  5. "작성자를 신뢰합니까?" 창이 뜨면 예, 신뢰합니다 (Edge는 주소줄 아래 "제한 모드" 줄에서 관리 → 신뢰). 터미널에 입력 줄이 안 나오면 ☰ → 터미널 → 새 터미널
  6. 터미널에 npm test → 빨간색이 정상 (30 failed | 28 passed 정도, 숫자는 항목 수)

코딩하기 = 빈칸 숙제를 AI와 함께 채우고, 자동 채점기로 확인하기

처음 한 번은 연습! (두 번째 종이, 연습 안내서를 보면서 따라 하세요) src/warmup/warmUp.ts → npx vitest run warmUp 이 초록색이 되게 (연습용이라 GitHub에 안 보냄: 아래 "올리기"의 git add(보낼 파일 고르기)에 이 파일을 넣지 않기)

  1. 숙제지 열기: 왼쪽 목록 src → tasks → 내 번호 파일. 안에 TODO라고 적힌 곳이 내가 채울 빈칸입니다.
  2. 채점기 돌리기: 터미널에 npx vitest run task0N (N = 내 번호) → 빨간색이면 정상 (아직 빈칸이라서)
  3. AI에게 부탁하기: BeAT(beat.busanedu.net → 개인 도우미)에 숙제지(내 파일) + 채점 기준(내 테스트) + 설명서(taskTypes.ts)를 붙여 넣기. 붙여 넣기 전에 "아래 파일의 TODO 빈칸을 채워 줘. 테스트를 모두 통과해야 하고 테스트는 바꾸지 마."라고 직접 쓰기 (Enter는 마지막에 한 번만)
  4. 답 옮기기: AI가 준 코드를 내 파일의 TODO 빈칸 안에만 붙여 넣기 (자동 저장)
  5. 다시 채점: 같은 명령 → 초록색이면 성공! 빨간색이면 터미널 오류를 복사해 BeAT에 붙여 넣고 고쳐 달라고 하기
  6. 설명하기: 초록색이 되면 옆 친구에게 "이 코드가 하는 일"을 내 말로 설명하기 (모르는 줄은 BeAT에게 질문)

올리기 (내 코드를 GitHub로 보내기 = push)

터미널에 입력할 명령하는 일
git status바뀐 파일이 뭔지 확인 (내 파일만 있어야 함)
git add src/tasks/내파일이름① 보낼 파일 고르기 ← 연습 파일(warmUp.ts)은 넣지 않기!
git commit -m "feat: 학생 N 첫 구현"② 보낼 내용에 이름 붙이기
git push③ GitHub로 보내기

꼭 지킬 것

  • 테스트 파일·타입 파일·다른 사람 파일은 고치지 않기, main에는 push 하지 않기
  • 실수로 다른 파일을 고쳤으면(git status에 modified로 보임) git restore 파일경로로 되돌리기
  • npm install로 새 라이브러리 설치하지 않기
  • 실제 학번·이름·전화번호·비밀번호를 BeAT나 코드에 쓰지 않기 (가상 학번은 9로 시작하는 5자리)
  • 끝나면 활동 기록 쓰기, 왼쪽 아래 Codespaces → Stop Current Codespace
막히면  403 오류 → 초대 수락 안 함  /  화면이 안 열림 → 선생님께  /  터미널 명령이 낯설면 → 옆 친구와 한 줄씩
