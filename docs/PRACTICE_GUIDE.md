# 코딩 시작 따라하기 — 연습 과제 자세히

축제 모바일 교환권 프로젝트 · Codespace 화면이 열린 뒤부터 · 처음 코딩해도 괜찮습니다. 한 칸씩 따라 하세요.

> 출력용은 `docs/PRACTICE_GUIDE.pdf`(A4 양면 2쪽)입니다.

## 0. 화면은 세 칸으로 나뉘어 있습니다

```
┌──────────────┬───────────────────────────────┐
│ ① 파일 목록  │ ② 편집기 (코드가 보이는 곳)   │
│ (왼쪽)       │  → 코드를 붙여 넣고 고치는 곳 │
│  .devcontainer├──────────────────────────────┤
│  docs        │ ③ 터미널 (아래 까만 곳)       │
│  src         │  → 명령을 입력하는 곳         │
└──────────────┴───────────────────────────────┘
```

- **② 편집기** = **코드를 붙여 넣고 고치는 곳.** BeAT가 준 코드는 여기에 넣습니다.
- **③ 터미널** = **명령을 입력하는 곳.** `npx vitest run warmUp` 같은 글자를 치고 **Enter**를 누릅니다. **코드는 여기에 붙여 넣지 않습니다.**

## 1. 연습 과제가 뭔가요?

`welcomeMessage`라는 함수가 별명을 받아서 **"안녕하세요, ○○님! 축제 모바일 교환권 프로젝트에 오신 것을 환영합니다."**를 돌려주게 만듭니다. 지금은 빈 글자(`''`)만 돌려줘서 테스트가 **빨간색(실패)**입니다. 이걸 **초록색(성공)**으로 바꿉니다.

## 2. 따라 하기 (7단계)

### 단계 1 — 연습 파일 열기

1. 왼쪽 **파일 목록**에서 `src`를 누릅니다. (폴더 앞 화살표 ▶가 ▼로 바뀝니다)
2. 그 안의 `warmup`을 누르고, `warmUp.ts` 파일을 누릅니다.
3. 가운데 **편집기**에 코드가 열립니다. 맨 아래쪽 `return ''` 줄이 우리가 고칠 곳입니다.

### 단계 2 — 먼저 "빨간색"을 확인하기

1. 아래 **터미널의 까만 곳을 마우스로 한 번 클릭**합니다. (깜빡이는 줄이 보여야 합니다)
2. 키보드가 **영어 상태**인지 확인합니다. (**한/영** 키)
3. 아래 글자를 그대로 치고 **Enter**를 누릅니다.

```bash
npx vitest run warmUp
```

빨간 글자가 나오고 맨 아래에 `Tests  3 failed (3)`가 보이면 **정상**입니다.

### 단계 3 — BeAT에게 코드를 부탁하기

1. 크롬 위쪽 **＋**를 눌러 새 탭을 열고 `beat.busanedu.net` → **개인 도우미**로 들어갑니다.
2. **Codespace 탭**으로 돌아와서, 편집기에서 `warmUp.ts`가 열린 상태로 **편집기 안을 클릭**하고 `Ctrl`+`A`(전체 선택) → `Ctrl`+`C`(복사)를 누릅니다.
3. **BeAT 탭**으로 가서 아래 질문을 쓰고, 그 뒤에 `Ctrl`+`V`로 붙여 넣습니다.
4. 같은 방법으로 왼쪽 목록의 `warmUp.test.ts`를 열어 전체 복사한 뒤, BeAT 입력칸에 이어서 붙여 넣고 보냅니다.

**BeAT에 쓸 질문 (그대로 쓰세요)**

> 나는 고1이고 TypeScript 초보야. 아래 ① 파일의 TODO 함수를 구현해 줘. ②의 테스트를 모두 통과해야 해.
> 규칙: 테스트는 바꾸지 말고, 함수 안의 코드만 써 줘. 코드를 준 뒤에 각 줄이 무슨 뜻인지 쉬운 말로 설명해 줘.
> ① (warmUp.ts 붙여 넣기)  ② (warmUp.test.ts 붙여 넣기)

### 단계 4 — 받은 코드를 편집기에 넣기

1. BeAT의 답에서 **코드 부분**을 마우스로 드래그해서 선택하고 `Ctrl`+`C`로 복사합니다. (코드 상자에 복사 버튼이 있으면 눌러도 됩니다)
2. **Codespace 탭**으로 돌아와 편집기에서 `return ''` 줄의 **맨 앞을 클릭**하고 `Shift`+`End`로 그 줄을 선택한 뒤 `Ctrl`+`V`로 붙여 넣습니다. (선택한 줄이 새 코드로 바뀝니다)
3. BeAT가 **함수 전체**를 줬다면, 연습 파일에서는 `Ctrl`+`A` → `Delete`로 전부 지우고 `Ctrl`+`V`로 붙여 넣어도 됩니다. 단, `export function welcomeMessage`라는 글자가 그대로 있어야 합니다.
4. 저장은 자동입니다. 탭 이름 옆에 **동그란 점(●)**이 남아 있으면 `Ctrl`+`S`를 누릅니다.

### 단계 5 — 다시 확인하기

터미널을 클릭하고 단계 2와 같은 명령을 다시 입력합니다.

```bash
npx vitest run warmUp
```

**초록색 ✓**와 `Tests  3 passed (3)`가 나오면 **성공!** 🎉

### 단계 6 — 또 빨간색이면 (실패했을 때)

1. 터미널의 **빨간 오류 글자**를 마우스로 **드래그해서 선택**하고 `Ctrl`+`C`를 누릅니다.
2. BeAT에 이렇게 씁니다: **"테스트가 실패했어. 오류 메시지는 이거야: (붙여 넣기) 고쳐 줘."**
3. 새로 받은 코드를 단계 4부터 다시 합니다.

**주의:** 글자를 선택하지 않고 터미널에서 `Ctrl`+`C`를 누르면 "실행 중지"입니다. 복사하려면 꼭 먼저 드래그하세요.

### 단계 7 — 내 과제로 넘어가기

1. 연습 파일은 **GitHub로 보내지 않습니다.** 연습만 하고 끝입니다. (`git add` 하지 않기)
2. 왼쪽 목록에서 `src` → `tasks` → **내 담당 파일**을 엽니다.
3. 똑같이 진행합니다. 다만 BeAT에 붙여 넣는 재료가 **3개**입니다: ① 내 파일 ② 내 테스트(`src/tasks/__tests__` 안) ③ `src/tasks/taskTypes.ts`
4. 내 테스트 명령은 `npx vitest run task0N` (N은 내 번호. 예: 3번이면 `task03`)
5. **내 파일에서는** 맨 위 `import` 줄과 `export function` 이름은 **그대로 두고**, TODO가 있는 함수 **안의 코드만** 바꿉니다.

## 3. 자주 하는 실수

| 이렇게 되면 | 이렇게 하세요 |
|---|---|
| 코드를 **터미널**에 붙여 넣었다 | 코드는 **가운데 편집기**에, 터미널엔 명령만 입니다. |
| 기존 `return ''`을 안 지우고 붙여 넣었다 | 그 줄을 지우고 새 코드로 바꿉니다. 안 지우면 오류가 납니다. |
| 명령이 안 먹는다 / 이상한 글자가 나온다 | **한/영** 키로 영어로 바꾸고, 대소문자까지 똑같이 칩니다. `warmUp`의 `U`는 대문자. |
| 터미널에 입력 줄이 없다 | 왼쪽 위 **☰ → 터미널 → 새 터미널**을 누릅니다. |
| 다른 파일이 바뀌었다 (잘못 눌러 고침) | 터미널에 `git status` → 바뀐 파일을 `git restore 파일경로`로 되돌립니다. 모르겠으면 선생님께 물어봅니다. |
| BeAT가 테스트를 고치라고 한다 | 테스트는 **고치지 않습니다.** "테스트는 못 바꿔, 코드만 고쳐 줘"라고 다시 부탁합니다. |

**복사·붙여 넣기 키:** 전체 선택 `Ctrl`+`A` · 복사 `Ctrl`+`C` · 붙여 넣기 `Ctrl`+`V` · 저장 `Ctrl`+`S` · 실행 `Enter`
