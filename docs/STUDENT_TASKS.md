# 10월 30일 학생 공동 개발 과제

고등학교 1학년 학생들이 AI의 도움을 받아 기능을 하나씩 완성하기 위한 안내서입니다. 한 번에 전부 만들지 말고 팀별로 과제 하나를 선택해 작은 변경과 테스트를 반복하세요.

> 모든 실습에는 `F-1001`, `F-1002` 같은 가상 학번만 사용합니다. 실제 이름, 학번, 연락처는 입력하거나 커밋하지 않습니다.

## 시작하기

```bash
npm install
npm run dev
```

수정 후에는 `npm run typecheck`와 `npm run build`를 실행합니다. 핵심 시작 파일은 `src/studentTasks.ts`이며, `TODO`를 검색하면 구현 위치를 찾을 수 있습니다.

## 과제 1: 학번별 코인 지급과 중복 방지

### 개발 목표
- 가상 학번으로 학생을 찾습니다.
- `축제 입장`, `세계시민 OX 활동` 사유마다 1코인을 지급합니다.
- 같은 학생에게 같은 사유로 두 번 지급하지 않습니다.

### 수정할 파일
- `src/studentTasks.ts`의 `grantCoinByStudentId`
- 완성 후 `src/App.tsx`의 운영진 화면에 입력 UI 연결

### 힌트
- `Array.map()`으로 선택한 학생만 새 객체로 바꿀 수 있습니다.
- `rewardedReasons.includes(reason)`이 참이면 원래 배열을 반환해 보세요.

### 테스트 방법
1. `F-1001`에게 `축제 입장` 코인을 한 번 지급합니다.
2. 잔액이 1 증가했는지 확인합니다.
3. 같은 작업을 반복해 잔액이 더 늘어나지 않는지 확인합니다.
4. 다른 사유는 한 번 지급되는지 확인합니다.

## 과제 2: 코인 차감과 교환권 발급

### 개발 목표
- 가상 학생의 보유 코인을 확인합니다.
- 선택한 간식의 필요 코인이 충분할 때만 발급하고 코인을 차감합니다.

### 수정할 파일
- `src/studentTasks.ts`의 `issueVoucherForStudent`
- 간식 가상 데이터 `src/mockData.ts`
- 완성 후 운영진용 교환권 화면에 연결

### 힌트
- 간식별 필요 코인은 배열 데이터로 분리하세요.
- 잔액 부족 결과를 `{ ok: false, message: '코인이 부족합니다.' }`처럼 표현해도 좋습니다.

### 테스트 방법
1. 잔액보다 저렴한 간식이 발급되는지 확인합니다.
2. 발급 후 잔액이 정확히 줄었는지 확인합니다.
3. 잔액보다 비싼 간식은 발급되지 않는지 확인합니다.

## 과제 3: QR 교환권 사용 처리

### 개발 목표
- 스캐너가 입력한 교환권 ID를 찾습니다.
- `issued` 교환권만 `used`로 변경합니다.
- 이미 사용됐거나 취소된 교환권의 중복 처리를 막습니다.

### 수정할 파일
- `src/studentTasks.ts`의 `markVoucherUsed`
- 완성 후 운영진용 교환권 사용 처리 화면 추가

### 힌트
- 2D 스캐너는 보통 키보드처럼 문자열을 입력하고 Enter를 보냅니다.
- 이번 실습에서는 QR을 실제 생성하지 말고 교환권 ID를 직접 입력하세요.
- 실제 중복 방지는 서버와 데이터베이스가 원자적으로 처리해야 합니다.

### 테스트 방법
1. `issued` 교환권이 `used`로 바뀌는지 확인합니다.
2. 같은 ID를 다시 입력했을 때 경고가 표시되는지 확인합니다.
3. 존재하지 않는 ID와 `cancelled` 교환권도 확인합니다.

## 과제 4: 게임별 자동 랭킹

### 개발 목표
- 종목별 참가자 코드와 점수 또는 기록을 입력합니다.
- 점수가 높은 종목과 시간이 낮은 종목을 구분해 정렬합니다.
- 종목 설정에 따라 TOP 5 또는 TOP 10을 표시합니다.

### 수정할 파일
- `src/studentTasks.ts`의 `calculateGameRanking`
- 랭킹 가상 데이터 `src/mockData.ts`
- 완성 후 운영진 입력 화면과 학생 조회 화면에 연결

### 힌트
- `higher`는 `b.score - a.score`, `lower`는 `a.score - b.score`로 정렬합니다.
- 종목을 `filter()`한 뒤 `sort()`하고 `slice(0, 5)`를 적용해 보세요.
- 동점 처리 방식은 구현 전에 팀원들과 먼저 정하세요.

### 테스트 방법
1. 점수형 종목에서 100점이 80점보다 먼저 나오는지 확인합니다.
2. 시간형 종목에서 42초가 51초보다 먼저 나오는지 확인합니다.
3. 다른 종목의 기록이 섞이지 않는지 확인합니다.
4. TOP 5 또는 TOP 10 개수를 넘지 않는지 확인합니다.
